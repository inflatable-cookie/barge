`barge init` no longer edits a repository's committed `AGENTS.md`. It writes the scratch rules to `AGENTS.local.md`, keeps that file out of Git through `info/exclude` (a linked worktree's entry lands in the main repository), and reports a missing pointer line or a leftover block in `AGENTS.md` without changing it. `init --check` and `doctor` follow the same file, and a binding that still names `AGENTS.md` is reported stale until `init` is rerun.
