Fixes a false "held" refusal on Linux: a non-waiting hold (`try_hold`, used by runs, returns, leases and prune) now retries for up to 200 ms before it refuses. A lock descriptor a concurrent spawn in the same process still holds across its fork stays taken for a moment after its holder drops it, so the refusal was spurious; a real holder still refuses, and a run still never waits for a return.
