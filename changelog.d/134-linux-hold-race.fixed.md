A non-waiting hold (`try_hold`, used by runs, returns, leases and prune) now retries a refusal up to 100 times, about 200 ms, before it refuses. This stops a spurious "held" refusal on Linux, where a lock still held across another thread's fork outlived its holder for a moment. A hold can land if contention clears inside the window; a holder still present when it ends still refuses, and a run never waits for a return to finish.
